## Die fünf zuerst

### 1. ⛔ Die gesamte Qualitätsschleuse ist toter Code — und das Produkt kann Platzhalter-Müll als Ergebnis ausweisen

**Nicht von Codex gefunden**, sondern beim Nachprüfen seiner Befunde: keiner der vier
Prüfer sah einen Aufrufer.

`main.py:461` baut das Framework über `create_default_framework()` und ruft in
`evaluate_results` **`score_text()` + `calculate_weighted_score()`** — die schlichten
Methoden. `score_text_with_quality_gates()` wird von **nichts** im Laufpfad aufgerufen,
nur von der Demo in `evaluation_scoring.py` selbst und von `test_critical_failures.py`.

Gemessen, beide Pfade auf denselben Texten:

| Eingabe | Pfad, den `main.py` nutzt | Pfad, den `CLAUDE.md` beschreibt |
| --- | --- | --- |
| gute, knappe Antwort | 0,298 | 0,050 |
| **reine Platzhalter-Vorlage** (`{solution}`, `[insert details here]`, `TODO`, `lorem ipsum`, `XXX`) | **0,292** | 0,050 |

Eine Antwort, die nur aus Platzhaltern besteht, ist im echten Lauf von einer guten nicht
zu unterscheiden. `CLAUDE.md` bewirbt genau das Gegenteil als Kernstück der
Überarbeitung: „Template Failure Auto-Disqualification", „Enhanced Buzzword Penalty
Engine", „Quality Gates: 5-tier filtering system prevents low-quality AI content from
reaching final findings".

**Was passiert, wenn es so bleibt:** Das Werkzeug wirbt mit einer Qualitätssicherung, die
es nicht ausführt. Ein Modell, das eine Vorlage zurückgibt statt einer Antwort, landet
möglicherweise unter den Top-Ergebnissen — und der Nutzer hat keinen Anlass zu zweifeln.

⚖️ **Nicht einfach anschalten.** Der Gate-Pfad ist selbst defekt (Punkt 2). Ihn ohne
Reparatur zu aktivieren, macht es schlimmer.

### 2. ⛔ Der Gate-Pfad würde, eingeschaltet, gute Antworten vernichten

Codex-Befunde 1–5 zu `evaluation_scoring.py`, alle empirisch bestätigt. `"..."` steht in
`PLACEHOLDER_INDICATORS` (`evaluation_scoring.py:200`) und wird per Teilstring geprüft
(`:220`); `r"\{.*\}"` (`:175`) trifft jedes JSON. Jeder Treffer setzt **alle** Kriterien
auf 0,05 (`:496`). Unter 50 Wörtern gilt als Fehlschlag (`:225`).

Gemessen an einer konkreten, mit Zahlen, Fristen, Kosten und Messwerten belegten
138-Wort-Antwort:

| Variante | Ergebnis |
| --- | --- |
| unverändert | 0,195 — und scheitert an `insufficient_implementation_details` |
| **+ ein Auslassungszeichen** | 0,050 |
| **+ ein JSON-Beispiel** | 0,050 |
| **+ das Wort „TODO" im Fließtext** | 0,050 |
| dieselbe Aussage in 21 Wörtern | 0,050 |

Die dichteste denkbare Antwort besteht die Schleuse nicht. **Erst reparieren, dann
anschalten** — in dieser Reihenfolge, sonst tauscht man ein stilles Problem gegen ein
lautes.

### 3. Die Auslieferung schreibt jedem Gewinner das falsche Modell und den falschen Rahmen zu

`reporting.py:227–232` zerlegt die Kombinations-Kennung an `_` und nimmt an, der
Modellname bestehe aus höchstens zwei Teilen. **Jedes** Modell unseres Portfolios hat
mehr.

Aus `run_summary.md` des Laufs von heute, wörtlich:

```
1. **or_claude with Sonnet Instruction** (Score: 0.414)
2. **or_mistral with Small Instruction** (Score: 0.400)
3. **or_claude with Sonnet Instruction** (Score: 0.397)
```

„Sonnet Instruction" und „Small Instruction" sind keine kognitiven Rahmen — es sind
Bruchstücke des Modellnamens. `or_claude` existiert in keiner Konfiguration. Die
tatsächlich beteiligten Rahmen (Integrativ, Disruption, Pragmatisch) stehen nirgends.

**Was passiert, wenn es so bleibt:** Die Kernaussage des Werkzeugs — *welcher* Denkansatz
welches Modells hat den besten Beitrag geliefert — ist in jedem bisherigen Bericht falsch.

*Behebung:* die Kombination per Kennung im strukturierten Datensatz nachschlagen und
`model`/`template` von dort lesen. Beide String-Zerleger (`:227`, `:363`) entfallen.

---

### 4. Ein Fehler im Bewerter wird zu einer 0,0 und ist von einer schlechten Antwort nicht zu unterscheiden

`evaluation_scoring.py:110–112` fängt **jede** Ausnahme je Kriterium, druckt sie und setzt
0.0. Das ist der **live** genutzte Pfad. Eine kaputte Bewertungsfunktion, ein
unerwarteter Eingabetyp oder eine spätere Regression sieht danach exakt aus wie eine
schwache Antwort — und verschiebt still die Rangfolge.

Dieselbe Krankheit hat diese Sitzung im Ausführungspfad dreimal behandelt; hier steht sie
noch.

*Behebung:* strukturierten Fehler je Kriterium zurückgeben, die Bewertung als **ungültig**
kennzeichnen statt als null, und über den Logger statt `print` melden.

---

### 5. CSV-Formelinjektion in `ideas.csv`

`reporting.py:848–857` schreibt Titel und Beschreibung roh in die CSV. Eine Modellantwort,
die mit `=`, `+`, `-` oder `@` beginnt, ist in Excel oder LibreOffice eine **aktive
Formel**. Der Text kommt von einem Modell, das auf eine beliebige Nutzerfrage antwortet.

*Behebung:* führende Formelzeichen in Textzellen mit einem Apostroph entschärfen. Ein
Einzeiler.

## Angenommene Risiken, mit Bedingung

| Risiko | Warum jetzt nicht | Wann neu entscheiden |
| --- | --- | --- |
| `query_generator.load_from_file`/`save_to_file` nehmen beliebige Pfade | kein Aufrufer, nicht erreichbar | **sobald irgendetwas sie aufruft** — besonders eine Flask-Route |
| Modell ohne Preis zählt als $0 | heute haben alle 14 Modelle Preise | sobald ein Modell ohne `pricing`-Block in die Konfiguration kommt |
| `selected_models` ≠ `params["models"]` | der Web-Pfad hält beide gleich (3/3 nachgeprüft) | sobald ein anderer Aufrufer die Schätzung nutzt |
| Berichte speichern Frage und Antworten ungeschützt | lokales Werkzeug, Läufe bleiben auf der Platte | sobald Berichte über eine Route ausgeliefert oder geteilt werden |
| Markdown-Injektion aus Modelltext | wird heute als Markdown gelesen, nicht als HTML gerendert | sobald ein Bericht im Browser als HTML gerendert wird |
| ungeprüfter Ausgabepfad in `reporting` | Aufrufer sind CLI und `app.py`, beide setzen ihn selbst | sobald ein Pfad aus einem Request stammt |
| `textstat` optional ⇒ installationsabhängige Ergebnisse | Auswirkung klein, Abhängigkeit stabil | sobald Läufe zwischen Rechnern verglichen werden |
| Duplikaterkennung je Aufruf neu | `generate_variations` wird je Lauf einmal gerufen | sobald mehrfach je Lauf gerufen wird |
